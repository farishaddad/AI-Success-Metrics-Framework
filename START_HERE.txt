📖 QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════════════

STEP 1: Install Node.js (One-time only)
────────────────────────────────────────
   → Go to: https://nodejs.org
   → Download the "LTS" version
   → Install it
   → Restart your computer

   Already have Node.js? Skip to Step 2!


STEP 2: Start the Dashboard
────────────────────────────────────────
   Windows Users:
   → Double-click: START_DASHBOARD.bat

   Mac/Linux Users:
   → Double-click: START_DASHBOARD.sh

   First time? Takes 2-5 minutes to install.
   Next time? Only 5-10 seconds!


STEP 3: Explore!
────────────────────────────────────────
   → Dashboard opens in your browser automatically
   → Click tabs at the top to see different views
   → Hover over charts for details
   → Click red dots (⚠) for incident reports

🛑 STOPPING THE DASHBOARD

❓ HAVING PROBLEMS?
═══════════════════════════════════════════════════════════════════

Dashboard won't start?
   → Read TROUBLESHOOTING.md
   → Section: "npm not found"

Browser doesn't open?
   → Look for "http://localhost:5173" in terminal
   → Copy and paste into browser

Charts not showing?
   → Refresh page (F5)
   → Try Chrome or Edge browser

Still stuck?
   → Read USER_GUIDE.md
   → Contact IT department
