# ⚡ Quick Start - AI Success Metrics Dashboard

## 🎯 For Non-Technical Users

### What is this?
A beautiful, interactive dashboard that shows AI program performance metrics, ROI, and business impact.

---

## 🚀 Getting Started (3 Steps)

### Step 1: Install Node.js (One-time setup)

**Do you have Node.js installed?**
- Not sure? Continue to Step 2 and see if it works!
- If you get an error, come back here.

**To install Node.js:**
1. Go to: https://nodejs.org
2. Click the big green button that says "LTS" (recommended)
3. Download and install (just click Next/Continue)
4. **Restart your computer**

---

### Step 2: Start the Dashboard

**Windows Users:**
- Double-click `START_DASHBOARD.bat`
- Wait 10-30 seconds
- Dashboard opens in your browser automatically!

**Mac/Linux Users:**
- Double-click `START_DASHBOARD.sh`
- If asked, click "Open" to allow
- Wait 10-30 seconds
- Dashboard opens in your browser automatically!

**First time?** It will take 2-5 minutes to install packages. Subsequent runs are much faster!

---

### Step 3: Explore!

Click the tabs at the top to see different dashboards:
- **Executive Overview** - Overall health and ROI
- **Business Impact** - Revenue and market metrics
- **Operational Efficiency** - Process improvements
- **Model Performance** - Technical AI metrics
- **Customer Experience** - Customer satisfaction
- **Innovation Capacity** - Innovation tracking
- **Economic Efficiency** - Financial analysis
- **ROI Tracking** - Detailed ROI breakdown
- **Project Details** - Individual project view

**Interactive Features:**
- Hover over charts to see details
- Click red incident dots (⚠) for detailed reports
- Select different projects in Project Details tab

---

## 🛑 Stopping the Dashboard

**When you're done:**
1. Go to the black/terminal window
2. Press `Ctrl + C`
3. Type `Y` if asked
4. Close the window

---

## 📤 Sharing with Others

### Option 1: Share the Folder
1. Zip this entire folder
2. Send to colleagues
3. They run `START_DASHBOARD.bat` or `START_DASHBOARD.sh`

### Option 2: Build Standalone Version
1. Run `BUILD_FOR_SHARING.bat` (Windows) or `BUILD_FOR_SHARING.sh` (Mac/Linux)
2. Wait for build to complete
3. Share the `dist` folder
4. Recipients open `dist/index.html` in their browser
5. No installation needed!

### Option 3: Host Online
See `DEPLOYMENT_GUIDE.md` for hosting on the internet.

## ❓ Having Problems?

### Dashboard won't start?
→ See `TROUBLESHOOTING.md` - Section: "npm not found"

### Browser doesn't open?
→ Look for `http://localhost:5173` in the terminal window
→ Copy and paste into your browser

### Charts not showing?
→ Refresh the page (F5)
→ Try a different browser (Chrome recommended)

### Still stuck?
→ Check `USER_GUIDE.md` for detailed help
